# SK Designer Studio - Digital Catalog

A beautiful, responsive digital catalog for SK Designer Studio showcasing portfolio, services, and contact information.

## Features

- 🎨 Modern, responsive design
- 📱 Mobile-friendly interface
- 🚀 Fast loading with optimized assets
- 💼 Portfolio showcase
- 🛠️ Services section
- 📞 Contact form
- ✨ Smooth animations and interactions

## Getting Started

### Prerequisites

- Python 3.x (for local server)
- Modern web browser

### Installation

1. Clone or download this repository
2. Navigate to the project directory
3. Start the local server

### Running the Application

```bash
# Start the server on port 3000
python3 -m http.server 3000

# Or use npm scripts
npm start
```

Then open your browser and go to: `http://localhost:3000`

## Customization

### Adding Your Content

1. **Portfolio Items**: Edit the portfolio section in `index.html` to add your projects
2. **Services**: Update the services section with your offerings
3. **Contact Information**: Modify contact details in the contact section
4. **Branding**: Update colors, fonts, and logo in `styles.css`

### Adding Images

Replace the placeholder images in the portfolio section with your actual project images:

```html
<div class="portfolio-image">
    <img src="path/to/your/image.jpg" alt="Project Description">
</div>
```

### Styling

The design uses a modern color scheme:
- Primary: #e74c3c (Red)
- Secondary: #2c3e50 (Dark Blue)
- Accent: #667eea (Purple gradient)

You can customize these colors in the CSS variables or directly in `styles.css`.
